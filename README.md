
# 📝 Notes App (Vite + Vanilla + TypeScript)

A lightweight notes app built with **Vite** and **TypeScript** — no frameworks.  
You can **create** and **delete** notes from a list, all handled with plain DOM manipulation.

---

## 🚀 Features

- Add new notes
- Delete existing notes
- Delete multiple notes
- Delete with double click
- Undo last change
- Lightweight and framework-free  
- Written entirely in TypeScript

---

## 🧩 Tech Stack

- [Vite](https://vitejs.dev/) – Fast build tool  
- [TypeScript](https://www.typescriptlang.org/) – Typed JavaScript

---

## ⚙️ Installation

```bash
npm install
```

## 🧠 Usage
